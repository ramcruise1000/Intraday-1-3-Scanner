# Scanner V33 Setup Guide

## What is this?
This is a SECOND trading system that runs alongside your existing v3.2 system.

## Key Differences
- Session: 09:30 AM to 2:30 PM IST
- Separate journal in journal_v33/ folder
- 10-day learning window
- Strict quality filters (7/10 minimum score)

## Daily Operation
1. 9:30 AM: Both systems start scanning
2. 2:30 PM: V33 stops giving new signals
3. 3:10 PM: Both systems square off
4. Evening: Check journal_v33/daily_summary_v33.csv
